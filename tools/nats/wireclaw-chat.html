WireClaw Chat

connecting...

The AI runs on the PC (Ollama). Answers take a few seconds. The board keeps chat history: send /clear if answers look stale.

Examples

Click one to put it in the message box, check it, then press Enter. Send one request per message: the small AI model does one clear step well and mixes up long ones.

Tips

  • Use the tool words the agent knows: sensor_name, condition lt / gt, threshold, interval_seconds, on_action, off_action, payload.
  • {value} in a message is replaced by the real reading when the rule fires.
  • Say interval_seconds 1, or the rule is checked only every 5 seconds.
  • Registering and asking work in plain words (tested 3/3). For rules, copy the field-style examples and change only names and numbers (tested 8/8 and 4/4). A plain sentence like "publish X when below 20, and Y when it goes back above" worked only 1 time in 8: the model made two opposite rules, a wrong one, or none.
  • "Goes back above" is the same rule's off action, never a second rule. The board now refuses an exact opposite rule (same sensor and threshold, lt ↔ gt) and a rule with no on_action.
  • Two rules on the same condition are fine (e.g. object speaks, close_led lights GPIO 2).
  • Delete by ID (rule_01), never "the rules": the delete tool also accepts "all".
  • Order: register the device first, then the rule that uses it. When deleting: rule first, then the device.
  • Check the result on the board's page: 192.168.1.155 → Devices / Rules.
